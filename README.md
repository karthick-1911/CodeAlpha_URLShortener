# CodeAlpha URL Shortener

A URL Shortener backend built with Node.js, Express.js and MongoDB.

## Features
- Shorten any long URL
- Redirect short URLs to original URLs
- Data stored in MongoDB

## Tech Stack
- Node.js
- Express.js
- MongoDB + Mongoose
- nanoid

## How to run
1. Clone the repo
2. Run npm install
3. Add .env file with MONGODB_URI
4. Run node index.js
